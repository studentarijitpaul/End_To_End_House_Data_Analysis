About the project

A housing model, presented as an application.

This site takes the models trained in the notebook and makes them available through a clear client-facing interface.

01

Training data

Property facts become model features.

Location, property size, configuration, construction year, facilities, and availability information are prepared for regression modelling.

02

Trained models

Several regression methods are saved.

The app loads `features.pkl` to preserve the training column order, then lets a visitor choose a saved estimator.

03

Prediction

Browser input is made model-ready.

The Flask backend validates the form, recreates the one-hot encoded input row, and returns a price estimate in lakhs.

Project setup

Keep the saved models with the application.

The app expects `features.pkl` and each trained `.pkl` model in the top-level `Models` folder. It discovers them automatically when the server starts.
